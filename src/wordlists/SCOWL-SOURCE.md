# English vocabulary source

SCOWL 2020.12.07; ordinary words through size 60, English + American + British (including -ize spellings).
Only original lowercase ASCII entries of length 2-7, sorted and deduplicated. Excludes separate proper-name, upper, abbreviation and special categories. Includes inflected words. All single-letter entries are removed. Two-letter words are restricted to this conservative project allowlist: am, an, as, at, be, by, do, go, he, hi, if, in, is, it, me, my, no, of, oh, on, or, ox, so, to, up, us, we. Other valid but less common two-letter words are intentionally excluded. This is a bounded spell-checking vocabulary, not every possible English word.
